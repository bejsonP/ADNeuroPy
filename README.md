# Analiza Danych Neurofizjologicznych w środowisku Python

Materiały do zajęć dla studentów kognitywistyki na Uniwersytecie Jagiellońskim w roku akademickim 2026/2027.

**Język zajęć:** polski 🇵🇱  
**Środowisko pracy:** Python i Jupyter Notebook

## Korzystanie z materiałów

Materiały są uporządkowane według kolejnych zajęć. Notebooki (`.ipynb`) można przeglądać bezpośrednio na GitHubie, a do uruchamiania kodu i wykonywania ćwiczeń należy otworzyć je w środowisku obsługującym Jupyter Notebook, np. w VS Code.

## Aktualizacje

Repozytorium jest uzupełniane w trakcie semestru. Przed kolejnymi zajęciami sprawdź, czy pojawiły się nowe materiały lub zmiany w notebookach.
